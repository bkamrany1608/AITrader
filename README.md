# AI Trader Agent (Android, Kotlin + Compose)

ایجنت تحلیل و معامله کریپتو روی گوشی: داده زنده → بازسازی چارت → سقف/کف، S/R، خط روند، اسمارت‌مانی، پروفایل حجم →
سیگنال با احتمال کالیبره‌شده → حساب مجازی / بروکر (Binance Futures Testnet یا واقعی) → مدیریت معامله → گزارش اکسل.

## ساخت APK
1. پوشه را در یک ریپوی GitHub آپلود کنید (شاخه main).
2. تب Actions ← «Build APK» ← Run workflow. فایل `AITrader-apk` را دانلود و نصب کنید.
   (یا با Android Studio باز کنید و Run بزنید.)

## راه‌اندازی
- تنظیمات ← ماژول‌ها و ستاپ‌ها را روشن/خاموش کنید.
- تلگرام: توکن + Chat ID (در ایران معمولاً پروکسی HTTP یا آدرس آینه API لازم است).
- داشبورد ← «🔋 بهینه‌سازی باتری» را اجازه دهید، سپس «شروع».
- اولین اجرا: آموزش اولیه از ۱۰۰۰ کندل تاریخچه هر نماد (چند دقیقه).
- بروکر: ابتدا Testnet (کلیدهای testnet.binancefuture.com)، فقط حالت One-way. برای حساب واقعی دو کلید «حساب واقعی» و «تأیید نهایی» لازم است.

## منطق ریسک
- 1R = ریسک٪ × موجودی. حجم طوری محاسبه می‌شود که ضرر در حد ضرر ≤ 0.3R باشد (قابل تنظیم).
- خروج زودهنگام در ‎-0.2R‎ اگر احتمال ادامه زیر آستانه برود.
- پله‌ها بر پایه U = فاصله حد ضرر؛ تریلینگ ATR؛ خروج در اصلاح >20٪ سود ماکزیمم؛ ورود مجدد پس از پایان اصلاح؛
  معامله خلاف جهت / در جهت اصلاح عمیق با ریسک کم‌تر؛ هرم فقط با تأیید ادامه روند.
- سقف ضرر روزانه، توقف پس از N ضرر متوالی، سقف معاملات باز و هم‌جهت، کلید اضطراری.

## احتمال و یادگیری (صادقانه)
- «احتمال مدل» = ترکیب پیشین کیفیت + رگرسیون لجستیک آنلاین + نرخ برد تجربی هر ستاپ/رژیم.
- «کران آماری» = کران پایین Wilson نرخ برد تجربی. تا نمونه کافی نباشد معامله واقعی/تلگرام نمی‌رود، فقط معاملات «سایه» برای یادگیری.
- هدف ۷۰٪/۸۰٪/۹۵٪ قابل تضمین نیست؛ آستانه‌ها را بالا ببرید، سیگنال‌ها کم می‌شود. جدول Calibration در اکسل نشان می‌دهد پیش‌بینی‌ها با واقعیت می‌خوانند یا نه.

## ثبت دستی
تب «سیگنال دستی»: متن تلگرام را بچسبانید ← بررسی (نماد، جهت، هندسه SL/TP، RR، قیمت زنده، فاصله SL با ATR، نظر مستقل ایجنت، سقف‌های ریسک) ← تأیید و اجرا.
